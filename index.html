RTMP Relay Server

Fallback solution for when Twitch streams go down

How It Works

This project creates a serverless RTMP relay that can be deployed to Vercel. When your Twitch stream goes down, viewers can be redirected here to continue watching.

Setup Instructions

  1. Download the project files
  2. Upload to Vercel
  3. Configure your streaming software to use the provided RTMP endpoint
  4. Add this URL as a backup in your stream setup
